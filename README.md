# Output devices — IGCSE ICT

Interactive lesson for Pearson Edexcel International GCSE ICT, **Unit 1 Digital devices: Output** (book pages 32–37). Only these pages are covered (storage starts on page 38).

Each section is explained step by step with interactive simulations, followed by the book's **activities** (where the book has them) and a short auto-marked **✓ Check**. Each part ends with a **test** (multiple choice + exam-style questions with mark schemes).

**Part A · Monitors and printers** (pages 32–35)

1. Output and monitors — forms of output, screen size measured diagonally, resolution in pixels, standby mode, monitors over time and touch screens → Activities (Using monitors) → ✓ Check
2. Printers — dot matrix (impact through a ribbon, carbon copies), inkjet (CMY + black cartridges, tiny dots), laser (charged drum, laser, toner, heat), Table 1.3 and “Which printer?” → ✓ Check
3. 3D printers — digital model, layers of heated material from the bottom to the top, long printing times, uses → Activities (Using 3D printers, Technology and ethics) → ✓ Check
4. Plotters — professionals, CAD on large sheets, pen raised and lowered, paper rolled backwards and forwards, cutter for vinyl → ✓ Check
5. Test Part A

**Part B · Projectors, sound and control** (pages 36–37)

6. Data projectors — uses, light bulbs and lumens, resolution, optical vs digital zoom, portability → Activities (Types of projector) → ✓ Check
7. Speakers — mono, stereo and surround sound, amplifier and spatial awareness, low-quality speakers in alarms and buzzers → Activities (Different types of sound, Using low-quality speakers) → ✓ Check
8. Control devices (actuators) — valves, pistons, heaters, coolers, motors; a greenhouse control system; robots and nanorobots → ✓ Check
9. Test Part B · Key terms (searchable)

**Progress that students can share and resume** (same system as the other lessons)

- Saved automatically in the student's browser (`localStorage`, key `od-progress-v1`).
- **My progress** shows the percentage completed, with **Copy my progress** / **Download .txt** for the teacher, and a **progress code** (`OD1Z.…`) to carry on with another device.
- Nothing is sent to a server. Sounds (dot matrix, speakers, alerts) only play after a click.

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F), Help (?). Each scene has its own URL, e.g. `#printer` or `#check-speaker`.

Visual style: British School Alzira · Xàtiva · Gandia (BS Format: navy, school blue, yellow step markers). Plain HTML, CSS and JavaScript — no build step.
